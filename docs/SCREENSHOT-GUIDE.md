# Screenshot guide

This is your personal portfolio, so approved screenshots of the real public website can be included. Recommended gallery order:

1. `01-homepage-hero.png` — hero positioning, proof metrics, and system visual.
2. `02-selected-work.png` — selected-work grid with technology labels and outcomes.
3. `03-services-process.png` — service positioning and delivery model.
4. Contact UI should only be published after all direct contact details are replaced with fictional placeholders; no contact capture is currently included.

Before committing, remove private inbox/database records, API keys, admin-only screens, unpublished client names, browser profile data, and internal URLs. Public name, portfolio branding, public social links, and the portfolio domain are fine when they are intentionally part of your personal brand. Keep captures at a consistent 16:10 or 4:3 crop and export at a readable resolution.
